# Yeah Music 🎶

**Yeah Music** 是一个基于 **Flutter** 开发的跨平台音乐应用，基于我个人使用场景而开发的本地音乐播放器，完全免费，不设置任何 VIP 或者付费解锁的功能，希望也能为同样喜欢本地音乐的你带来纯粹、轻松的使用体验。

> 补充：  
> 从 `2.0.0` 版本开始，因为一些原因（非技术原因），无法继续公开源码，本仓库只做发包使用；  
> 所发布的 **Lite** 公开版本绿色安全，可以放心使用；  
> 如不信任或不慎安装该 APP，卸载即可；  
> 本仓库内源码，以供学习交流使用。

## ✨ 功能特性

### 🎶 本地音乐入库

- 多目录扫描，本地音频一键纳入曲库
- 支持格式：`mp3 / m4a / wav / flac / opus / ogg`
- 多歌单，支持高度自定义
- 曲库统计图表化，手机与桌面都更好用
- 自 v5 起曲库索引改用 **SQLite**（大曲库更稳）；升级后请重新添加音乐源并扫描

### 🏠 首页枢纽

- 模块可编排：显隐 / 顺序自由调整
- 入口：问候 · 搜索 · 继续播放 · 常用功能
- 曲库预览：我的歌单 · 艺术家 · 专辑 · 最近 / 最多播放
- 个性模块：声纹星环 · 叠影唱机 · 星潮共鸣 · 暮叶轻歌 · 山涧花信 · 花漾心事 · 暖心打卡（部分默认隐藏）

### 🎧 播放体验

- 统一队列承接本地 / Jellyfin / OneDrive 等来源
- 迷你条 → 播放页：封面 · 进度 · 歌词 · 音效
- 播放模式 · 休眠定时 · 均衡器 · 倍速等
- 桌面端支持多播放页扩展、窗口位置/大小记忆

### 🧾 元信息管理

- 自动读取内嵌标签、封面与歌词（不支持外链歌词和封面）
- 支持编辑内嵌标签与歌词相关信息
- 可重新加载嵌入数据，修正元信息不同步 / 缺失
- 查询时可预览波形并点击跳转播放

### 📚 歌词体验

- 多行歌词 / 多翻译按同一时间戳自动渲染
- 三种状态颜色 / 渐变：正在播放 / 已播过 / 未播到
- 可调字体大小、行距、对齐方式；点击行可定位进度
- 支持在通知与车机场景显示歌词（跟随歌词样式设置）
- 可以自己创作编写歌词，内置**歌词同步**组件已提供支持

### 🖥️ 桌面歌词

- 悬浮歌词窗可拖动、可锁定位置
- 背景透明度可调
- 与播放页同一套歌词样式（颜色、多行、翻译等）
- 可设置当前行前后各显示多少条「按时间轴分段」的歌词

### 🎛️ 主题与 UI

- 背景：纯色 / 自定义强调色 / 壁纸（模块化）
- 自定义字体 · 渐变背景
- 壁纸可雾化与压暗，提高界面辨识度

### 🎚️ 音效与听感

- **音量均衡**：按曲 / 按专辑扫描并写入 ReplayGain；可暂停后续写、覆盖已有标签；播放页「更多」可查看本曲增益
- 均衡器与音量均衡合并在「音效」页；预设图标按效果区分

### 🎸 吉他调音

- 常用功能内本地听音调音
- 标准 / 降半音 / Drop 等预设；逐弦引导与参考音；可调 A4（默认 440Hz）

### 🖥️ Jellyfin

- 独立浏览：歌曲 / 专辑 / 艺术家 / 流派 / 播放列表
- 流式播放与下载缓存；与 OneDrive 共用统一传输队列
- 按网络自动选码率；播放上报、歌单管理与搜索等

### ☁️ OneDrive 云端

- 云端曲库：索引网盘音乐文件夹，下载 / 删除、按需缓存、离线播放
- OneDrive 浏览器：浏览云盘目录，查看并播放音频
- 传输队列：批量上传 / 下载
- 本地上传：曲库多选或单曲上传
- 云端备份：歌单与设置等按需同步，支持从云端恢复；可导出本地 zip
- 缓存并入曲库：已落地文件与「音乐源」扫描结果合并为统一曲库

### 🖥️ 跨平台支持

- Android
- macOS
- Linux（KDE / GNOME）
- Windows

## 🗺️ 业务架构（Lite）

Yeah Music 以 **本地曲库** 为中心：首页聚合入口，播放体验贯穿各来源；Jellyfin / OneDrive 扩展内容获取；标签 / 歌词 / 识曲 / 音量均衡增强曲目信息。数据仅存本机，**不收集隐私**。

<p align="center">
  <img src="./README.assets/yeah_music_操作与数据流转_lite.png" alt="Yeah Music Lite 操作与数据流转" width="100%"/>
</p>

**读图提示**

| 域 | 做什么 |
| --- | --- |
| 首页枢纽 | 问候、搜索、继续播放、常用功能与曲库预览；个性模块可编排 |
| 本地曲库 | 扫描入库、浏览与自建歌单，是播放与编辑的主数据源 |
| 播放体验 | 统一承接本地 / 云端曲目，叠加歌词与播放控制 |
| Jellyfin / OneDrive | 服务器库与云盘听歌、传输与备份（不同步整库音频） |
| 内容增强 | 音量均衡、元信息匹配、歌词编辑、识曲与调音，结果写回本机 |
| 数据落点 | SQLite 曲库 · 设置偏好 · 本机文件 · 可选远端服务 |
